####mongodb database important command ####

Download MongoDB Database Tools and put the "mongodump" and "mongorestore" file from "MongoDB Database Tools" to your local mongodb bin folder
MongoDB Database Tools downlaod link: 
    https://www.mongodb.com/try/download/database-tools#:~:text=MongoDB%20Command%20Line%20Database%20Tools%20Download

#Export All Collections (Full Database Backup)
For a local database: 
    mongodump --db your_database_name --out /path/to/output_directory
Export to a compressed file
    mongodump --db your_database_name --archive=my_database.gz --gzip

For a remote database or MongoDB Atlas:
    mongodump --uri="mongodb+srv://username:password@cluster.mongodb.net/your_database_name" --out /path/to/output_directory


#Import All Collections (Full Database Restore)
To a local database:
    mongorestore --db your_database_name /path/to/output_directory/your_database_name
Import from a compressed file
    mongorestore --db your_database_name --archive=my_database.gz --gzip

To a remote database or MongoDB Atlas:
    mongorestore --uri="mongodb+srv://username:password@cluster.mongodb.net/your_database_name" /path/to/output_directory/your_database_name
